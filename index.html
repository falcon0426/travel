6月の青森ポイント
6月は奥入瀬渓流の新緑のベストシーズン。5月中旬〜6月中旬は苔と若葉が最も美しい時期で、人出も夏休みや紅葉期ほど多くなく、ゆっくり歩けます。早朝には朝靄に木漏れ日が差し込む幻想的な光景も。気温は日中20℃前後／早朝は10℃以下まで下がる日もあるので羽織もの必須です。

DAY 1 ― 6/12(金)：移動&青森市ステイ（公共交通）

テーマ：初日はレンタカーなし。新幹線→JR→徒歩で身軽に
14:44東京駅発
はやぶさ号で新青森へ。指定席のE席（2人席窓側）がおすすめ。仙台・盛岡を経由。駅弁を仕入れて車内で軽く食事しておくと、青森市内ではしっかり夕食を楽しめる。
17:54新青森駅着 → JR奥羽本線に乗り換え
新青森駅から青森駅までJR奥羽本線で約6分・運賃200円。ICカード（Suica/PASMO）利用可。本数は1時間に1〜2本程度なので、新青森到着の接続列車を事前確認。乗り換え時間は構内移動含めて15分は見ておくと安心。荷物多めならタクシー（青森駅周辺ホテルまで約2,500円）も選択肢。
18:20頃青森駅着 → ホテルへ徒歩チェックイン
青森駅周辺ホテル（リッチモンド・JALシティ等）は徒歩5〜10分圏。雨でも傘で対応可能な距離。荷物を置いて身軽に夜の街へ。
19:30夕食：青森駅周辺で郷土料理&海鮮
候補：「お食事処 おさない」（ホタテ料理が看板、地元客にも人気）／「酒肴 旬」「ふじ寿司」などの寿司・居酒屋／「のれそれ食堂」（青森・南部の郷土料理が一気に楽しめる）。
注文したい一品 → 大間マグロ／ホタテ貝焼き味噌／いちご煮（ウニとアワビの潮汁）／せんべい汁／じゃっぱ汁。日本酒は「田酒」「豊盃」「陸奥八仙」など青森の銘酒を。
初日はレンタカー無しなのでアルコールも気兼ねなく楽しめるのがメリット。
22:00ホテルで就寝
翌朝は早起きしてのっけ丼朝食へ。
公共交通のメリット：初日はホテルに直行できるので到着後すぐに飲める／レンタカー受取の手間ゼロ。荷物が多くてもタクシー（新青森から青森駅周辺ホテルまで約2,500円）でも可。

DAY 2 ― 6/13(土)：青森市 → 八甲田 → 奥入瀬 → 十和田湖泊

テーマ：この旅のハイライト。新緑の渓流を全身で味わう
07:00朝食：のっけ丼（古川市場・青森魚菜センター）
青森駅から徒歩約5分。食事券12枚2,200円を購入し、市場内の店舗を回って自分好みの海鮮丼を作る名物体験。マグロ／ホタテ／イクラ／ウニはマスト。営業は7:00〜16:00、火曜定休（6/13は土曜なので営業）。
08:30ホテルチェックアウト → ねぶたの家 ワ・ラッセ
青森駅徒歩1分。5〜8月は9:00〜19:00営業。本物のねぶた大型山車4台を間近で見学でき、跳人体験や囃子の実演も。所要45〜60分。入場料 大人620円。荷物はホテルかワ・ラッセのコインロッカーに預けるとスムーズ。
10:00★ レンタカー受取（青森駅周辺）
青森駅から徒歩圏のレンタカー店舗で受取がおすすめ：
・オリックスレンタカー青森駅前店（青森駅徒歩2分）
・トヨタレンタカー青森安方店（青森駅徒歩6分／8:00〜19:00）
・ニッポンレンタカー青森駅東口（青森駅徒歩8分／8:00〜19:00）
受取手続きは20〜30分。事前ネット予約必須。レンタル期間は2日（6/13朝〜6/14夕方）になるので、新青森駅で2日半借りるより1万円弱安くなる。
10:45青森市内出発 → 国道103号で八甲田へ
青森市街〜奥入瀬は約60km・1時間30分が目安。途中ガソリン満タンに（山間部はGSが少ない）。
12:15城ヶ倉大橋（じょうがくらおおはし）
谷底まで122m、上路式アーチ橋としては日本最大級。展望デッキから八甲田連峰が一望。写真スポット。駐車場無料。15分滞在。
12:35八甲田ドライブ（車窓観光）
そのまま国道103号→394号を南下。睡蓮沼（すいれんぬま）や地獄沼などの絶景ポイントが点在。気になる所で5〜10分ずつ写真休憩。睡蓮沼は八甲田の山々を映す鏡のような景色で6月は新緑が美しい（駐車場無料）。
13:30ランチ：奥入瀬周辺で郷土料理
候補：「奥入瀬渓流館」レストラン（短角牛バーガー）／「OIRASE BEER 桂月」（地ビール&食事）／「やすみどころ 十和田屋」（ひめます塩焼き定食）／「十和田バラ焼き」を食べるなら十和田市街の「司」「司バラ焼き大衆食堂」。
※14:30LOの店もあるので13:30までに着くのがベター。
14:45奥入瀬渓流 散策（メイン）
おすすめは「石ヶ戸 → 雲井の滝 → 銚子大滝」の約4km・2時間コース。
・石ヶ戸（いしげど）駐車場に車を停める
・徒歩で阿修羅の流れ／雲井の流れ／白絹の滝
・雲井の滝でUターン、または銚子大滝まで歩いて駐車場へ戻る場合はタクシー or 路線バスを利用
・スニーカー必須、雨具携行（渓流沿いは天気急変あり）
・酸ヶ湯温泉に寄らない分、散策時間に余裕があるので、阿修羅の流れの撮影や馬門岩までの追加散策もおすすめ
17:00奥入瀬発 → 十和田ホテル（西湖畔）へ直行
焼山または石ヶ戸エリアから十和田ホテルまで、子ノ口経由で湖の北側を反時計回りに走行（約40km・約1時間）。湖を眺めながらのドライブ。途中の「瞰湖台（かんこだい）」展望台は時間があれば立寄り推奨（5分）。
18:00★ 十和田ホテル チェックイン
国登録有形文化財「秋田杉の館」。幻の1940年東京オリンピックに向け、北東北の宮大工約80名が秋田杉の巨木で建てた木造3階建ての名建築。玄関の吹き抜けと秋田杉の意匠が見事。
・チェックイン 15:00〜19:00（19時厳守、遅れる場合は事前連絡）
・所在：秋田県鹿角郡小坂町十和田湖西湖畔（青森から県境を越える）
・温泉（人工温泉）あり。湖を望む大浴場で散策の疲れを癒す。
19:00夕食（プラン付き）
十和田ホテルの和洋折衷ディナー。地元食材を使った創作料理。歴史ある館で味わうディナーは特別な時間に。食後はラウンジでゆっくりするのもおすすめ。

DAY 3 ― 6/14(日)：十和田湖 → 青森市 → 新青森

テーマ：早朝の奥入瀬と歴史文化／復路は時間との戦い
06:30朝の湖畔散策（十和田ホテル周辺）
西湖畔の静かな湖畔を散歩。早朝の湖面は鏡のように静か。6月は朝霧が湖面を覆うことも。文化財ホテルの外観撮影もこの時間がベスト。
08:00朝食（プラン付き）
十和田ホテルの朝食。秋田杉の意匠を眺めながらゆっくりと。
09:30チェックアウト → 発荷峠展望台
十和田ホテルから発荷峠展望台は約10分・近いのが地理的なメリット。十和田湖を一望、6月の早朝なら雲海が湖面を覆うことも。所要20〜30分。
※湖上派の場合は十和田湖遊覧船（休屋〜子ノ口、片道約50分、料金大人1,500円程度）。ただし休屋までは西湖畔から約40分かかるので時間配分注意。
11:00十和田湖発 → 青森市へ復路
西湖畔（発荷峠側）から青森市は国道103号・八甲田経由で約2時間。時間に余裕があれば、十和田市街経由で「道の駅とわだ」「駒街道（官庁街通り）」を散策する選択肢も（こちらは少し遠回り）。
13:30青森市内ランチ
候補：A-FACTORY（青森ベイエリアのお土産複合施設、シードル工房併設）の中のカフェ／「みなと食堂」（八戸の有名店だが青森市内にも類似店多数）／味の札幌 大西の「味噌カレー牛乳ラーメン」（青森B級グルメの代表）。
15:00三内丸山遺跡（さんないまるやま）
世界遺産「北海道・北東北の縄文遺跡群」構成資産。復元された大型掘立柱建物・大型竪穴住居は圧巻。所要60〜90分。常設展観覧料 大人410円。青森駅から車で約20分・新青森駅から約10分。
16:30レンタカー返却
返却前にセルフGSで給油。新青森駅周辺のGSは数が少ないので、青森市街で済ませる方が安心。返却は新幹線の30〜40分前を目安に。
17:00新青森駅でお土産タイム
「あおもり旬味館」でラグノオ3点セット（気になるりんご・パティシエのりんごスティック・いのち）／南部せんべい／ねぶた漬／いか塩辛／田酒などをまとめ買い。駅弁「ひとくちだら」「八戸小唄寿し」「とりめし」を新幹線車内用に。詳細は★お菓子お土産セクション参照。
17:33新青森駅発 → 東京 21:00 着
約3時間27分の新幹線旅。買った駅弁&お土産で打ち上げを。東京着後の予定がある場合は、新幹線内で簡単に整理しておくとスムーズ。

☔ 雨天時プラン（Plan B）

奥入瀬散策は雨でも決行！ 屋外景観スポットを屋内施設に振り替える構成
雨の奥入瀬は実は隠れた魅力
・雨で苔が水を含み緑が濃く鮮やかに発色。晴天時より美しいという声も多い
・霧と渓流が織りなす幻想的な雰囲気（写真は逆に良い）
・観光客が減って静かに歩ける
・苔・倒木・キノコをじっくり観察するならむしろベストコンディション

雨天時に変更するポイント

晴天時プラン→ 雨天時の振替先
城ヶ倉大橋（八甲田の絶景）霧で視界不良の可能性大 → スキップ or 短時間立寄り
八甲田ドライブ（睡蓮沼・地獄沼）視界悪く危険 → そのまま奥入瀬へ直行
発荷峠展望台（DAY3）雲海どころか何も見えない可能性 → 十和田市現代美術館へ振替
十和田湖遊覧船（DAY3）強風時は欠航 → 奥入瀬渓流館・苔玉づくり体験などへ
三内丸山遺跡 屋外展示そのまま縄文時遊館の屋内展示を充実させる

DAY2(6/13) 雨天時タイムライン

07:00朝食：のっけ丼（市場内・屋根あり）
市場は屋内なので雨でも快適。傘は古川市場の傘立てへ。
08:30ホテルチェックアウト → レンタカー受取
青森駅周辺のレンタカー店舗（オリックス／トヨタ／ニッポン）で受取。雨でも徒歩2〜8分圏。
09:30青森県立美術館（屋内）へ車で移動
ワ・ラッセよりこちらに変更がおすすめ。雨の日のアートはじっくり鑑賞向き。青森駅から車で約15分・無料駐車場あり。
・奈良美智「あおもり犬」（高さ8.5m）／シャガールのバレエ「アレコ」舞台背景画／棟方志功コレクション。
・営業 9:30〜17:00（入館16:30まで）、第2・第4月曜休館。
・一般 510円。あおもり犬連絡通路は雨天閉鎖の可能性あり（事前確認）。
11:00美術館発 → 奥入瀬へ直行
八甲田の絶景ポイントは霧でほぼ見えないので寄り道せず直行。所要約1時間30分。視界が悪い区間は速度を落として安全運転。
12:30ランチ：奥入瀬渓流館 or 屋根のある食堂
奥入瀬渓流館のレストランは屋根があり、雨を見ながらの食事も雰囲気あり。観光案内所も併設されているので散策情報を入手。
14:00★ 奥入瀬渓流 散策（雨天決行）
雨対策必須装備：
・ゴアテックス等のレインウェア上下（傘より両手が空いて快適）
・防水トレッキングシューズ（普通のスニーカーは中まで濡れる）
・カメラ用レインカバー or ジップロック（湿気でレンズが曇りやすい）
・ザックカバー＋着替え1セット

コース短縮案：雨で疲れやすいので「石ヶ戸 → 阿修羅の流れ → 雲井の流れ」（往復約2km・1時間）に短縮も検討。苔と滝の見どころはこの区間に集中。

注意：雨で遊歩道がぬかるみ・滑りやすい箇所多数。倒木や落石にも注意。雷鳴が聞こえたら即撤退。
15:30奥入瀬渓流館・モスボール工房（屋内）
散策後の濡れ体を温める。「苔玉づくり体験」（要予約・1,500円程度）など雨の日にぴったり。お土産にも◎。
17:00十和田ホテル（西湖畔）へ移動・チェックイン
奥入瀬→湖畔反時計回りで西湖畔へ約1時間。19時のチェックイン期限を守るため、雨天時は余裕を持って早めに出発。到着後は文化財建築をゆっくり鑑賞、温泉で冷えた体を温める。夕食付プランで温かいディナーを。

DAY3(6/14) 雨天時タイムライン

07:00早朝散策は天候を見て判断
小雨ならむしろ朝靄が美しく狙い目。本降りなら宿でゆっくり朝食 → 温泉再入浴。
09:30十和田ホテル出発 → 十和田市現代美術館へ
西湖畔から十和田市現代美術館まで約1時間20分（発荷峠経由）。雨天時は発荷峠展望台・遊覧船をスキップし、こちらへ振り替えるのが最適解。
10:30十和田市現代美術館
雨の日にぴったりの世界クラスの現代美術館。
・草間彌生の屋外彫刻（傘さして見られる）／ロン・ミュエクの巨大女性像「スタンディング・ウーマン」／オノ・ヨーコ作品など。
・営業 9:00〜17:00（入場16:30まで）、月曜休館（祝日は翌日）。
・常設展 一般1,800円。所要1.5〜2時間。
・併設の「Cafe Cube」でランチも可能。
12:30ランチ：十和田バラ焼き
美術館のすぐ近くに本場の店多数。「司バラ焼き大衆食堂」などで鉄板熱々の名物を。雨で冷えた体に染みる。
14:00十和田市発 → 青森市方面へ
十和田市から青森市は約1時間30分。下道（国道102/4号）。八甲田を通らないので雨天でも走りやすい。
15:30三内丸山遺跡（屋内中心で）
遺跡本体（屋外）は短めにして、縄文時遊館（屋内展示）を充実。出土品の常設展示「さんまるミュージアム」がメイン。雨でも問題なく楽しめる。
17:00レンタカー返却 → 新青森駅
雨天は道路が混みやすく所要時間が増える可能性大。30分早めに返却を目指す。

もし大雨・暴風警報が出たら（最悪ケース）

奥入瀬の遊歩道は増水・倒木の危険で通行止めになる可能性あり。その場合は無理せず：
・十和田ホテル館内で過ごす（文化財建築の鑑賞、温泉、ラウンジでゆっくり読書など）
・道の駅奥入瀬・道の駅とわだでお買い物
・十和田市現代美術館を前倒しでDAY2に組み込み
・最終手段で青森市内に戻りA-FACTORY・青森県立美術館でゆっくり

雨天時 追加の持ち物

必須追加アイテム

  • レインウェア上下（透湿性のあるもの推奨）
  • 防水トレッキングシューズ（or 防水スプレー処理した靴）
  • ザックカバー or 防水バックパック
  • 大きめのジップロック（カメラ・スマホ用）
  • 速乾性タオル2〜3枚
  • 着替え一式（特に靴下）

あると便利

  • 折りたたみ傘（短時間移動用）
  • 防水カメラ or スマホ防水ケース
  • くもり止めシート（レンズ・メガネ用）
  • 使い捨てカイロ（体を冷やさない）
  • ビニール袋（濡れ物・ゴミ入れ）
